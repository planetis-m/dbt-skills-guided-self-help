# DBT Skills Guided Self-Help

A skill for practicing one low-risk DBT-style skill for a specific everyday
difficulty.

It helps an adult examine what happened in a difficult moment, hold acceptance
and change together, and practice one skill from mindfulness, emotion
regulation, ordinary distress tolerance, interpersonal effectiveness, or
dialectical thinking.

## Boundaries

This skill is guided self-help, not comprehensive DBT, therapy, crisis care, or
a substitute for professional support. It does not handle suicidal or self-harm
urges, dangerous behavior, trauma processing, specialized mental health
treatment, or medication guidance.

## Session Records

At the end of a session, the skill proposes a focused personal recap. It saves
the approved recap to `dbt-sessions/`. If the user declines, stops, or does not
reply, no record is created.

The recap preserves the situation, the pattern noticed, the balance of
acceptance and change, the skill practiced, the main takeaway, and any practice
plan the user chose.

## Use

Invoke the skill and describe the everyday situation or skill you want to work
on:

```text
Use $dbt-skills-guided-self-help to guide me through a skills session.
```
